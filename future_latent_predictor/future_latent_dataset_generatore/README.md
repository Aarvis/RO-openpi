# VLA Future-Latent Sidecar Dataset Generator

This utility consumes the full pi0.5 image-embedding parquets generated by:

```bash
future_latent_predictor/Dataset creation/generate_future_latent_dataset.py
```

It writes compact future-latent sidecar parquets for VLA fine-tuning. It does not modify the original LeRobot datasets.

## Example

```bash
export CUDA_VISIBLE_DEVICES=0,1,2,3

uv run python future_latent_predictor/future_latent_dataset_generatore/generate_vla_sidecar_dataset.py \
  --config future_latent_predictor/future_latent_dataset_generatore/configs/example_vla_sidecar_generation.json
```

Override common paths from the command line:

```bash
uv run python future_latent_predictor/future_latent_dataset_generatore/generate_vla_sidecar_dataset.py \
  --config future_latent_predictor/future_latent_dataset_generatore/configs/example_vla_sidecar_generation.json \
  --embedding-data-root /scratch/real_robot_generated_dataset/output \
  --embedding-data-root /scratch2/sim_robot_generated_dataset/output \
  --output-dir /scratch2/vla_future_latent_sidecar/output \
  --resampler-checkpoint /scratch/future_latent_runs/resampler_autoencoder_v1/resampler_encoder_latest.pt \
  --future-predictor-checkpoint /scratch/future_latent_runs/future_predictor_v1/future_predictor_latest.pt \
  --batch-size 64 \
  --shard-size 1024
```

Only datasets with `include_in_future_latent_dataset=True` in the selected OpenPI training config are processed.

## Output Columns

Per row, the sidecar stores:

```text
top_future_latent_pred
right_wrist_future_latent_pred
left_wrist_future_latent_pred

top_future_latent_true
right_wrist_future_latent_true
left_wrist_future_latent_true

top_future_latent_valid
right_wrist_future_latent_valid
left_wrist_future_latent_valid

future_offset
episode_index
frame_index
index
task_index
source_dataset
```

Latents are stored as raw bytes with `latent_dtype` and `latent_shape` metadata columns.
